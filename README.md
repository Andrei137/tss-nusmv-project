# TSS Model Checking with NuSMV

NuSMV trebuie să fie accesibil în `PATH` ca `NuSMV` sau `nusmv`.

Din rădăcina repository-ului:

```bash
./curs/proiect/scripts/run.sh sum
./curs/proiect/scripts/run.sh --all
```

Sau din folderul scripturilor:

```bash
cd curs/proiect/scripts
./run.sh fibo.smv
./run.sh -all
```
